# سامانه مدیریت آزمایشگاه بتن (LIMS)

بک‌اند مدیریت آزمایشگاهی کامل برای آزمایش بتن و کنترل کیفیت پروژه‌های ساختمانی
ساخته‌شده با **Django + Django REST Framework**.

## قابلیت‌های اصلی

- مدیریت پروژه‌ها، مشتری‌ها و کارخانه‌های بتن
- چرخه کامل زندگی نمونه (کد، بارکد، QR، وضعیت، تاریخچه)
- انواع نمونه و انواع آزمون (کاتالوگ پویا و قابل توسعه)
- درخواست‌های آزمایشگاهی و اجرای آزمون
- مدیریت دستگاه‌ها، کالیبراسیون و جلوگیری از استفاده از دستگاه منقضی
- مخزن‌های عمل‌آوری (Curing)
- گزارش‌ها با نسخه‌بندی، تأیید امضادار و خروجی PDF
- کنترل کیفیت آماری (میانگین، انحراف معیار، داده‌های پرت، معیارهای پذیرش)
- داشبورد آماری، اعلان‌ها، مدیریت فایل و لاگ کامل فعالیت‌ها
- سیستم نقش‌ها و دسترسی کامل (RBAC)

## نقش‌ها

| نقش | شناسه | توضیح |
|---|---|---|
| مدیر سیستم | `admin` | دسترسی کامل |
| مدیر آزمایشگاه | `lab_manager` | مدیریت داده‌های آزمایشگاه |
| مدیر کنترل کیفیت | `quality_manager` | تأیید نتایج و گزارش‌ها |
| مهندس | `engineer` | درخواست آزمون و مشاهده نتایج |
| تکنسین | `technician` | ثبت نمونه، آزمون، عمل‌آوری |
| پذیرش | `reception` | دریافت نمونه، ثبت مشتری |
| مشتری | `client` | مشاهده پروژه‌ها و نتایج خود |
| فقط‌خواندنی | `readonly` | مشاهده کل داده‌ها بدون نوشتن |
| مدیر کارخانه | `factory_manager` | مدیریت کارخانه و مشاهده پروژه‌های مرتبط |
| ناظر | `supervisor` | مشاهده پروژه‌های تحت نظارت |

## نصب و اجرا

```bash
python -m venv .venv
.venv\Scripts\activate            # ویندوز
pip install -r requirements/base.txt
cp .env.example .env
python manage.py migrate
python manage.py create_admin admin
python manage.py runserver
```

- مستندات OpenAPI: `http://127.0.0.1:8000/api/schema/`
- سوییگر: `http://127.0.0.1:8000/api/docs/`
- ردوک: `http://127.0.0.1:8000/api/docs/redoc/`
- پنل ادمین: `http://127.0.0.1:8000/admin/`

## تست

```bash
python manage.py test api
```

## دستورات مدیریتی

```bash
python manage.py create_admin USERNAME [--password P] [--email E]
python manage.py notify_due_events [--within-days 14]
```

## معماری

- `api/models/` — مدل‌های دیتابیس
- `api/serializers/` — لایه سریالایز
- `api/views/` — ویوهای API
- `api/services/` — لایه سرویس و منطق کسب‌وکار
- `api/selectors/` — کوئری‌های خواندن و داشبورد
- `api/permissions.py` — کنترل دسترسی مبتنی بر نقش
- `api/access.py` — محدوده‌سازی کوئری بر اساس نقش
- `api/roles.py` — ثابت‌های نقش‌ها
- `api/signals.py` — پروفایل خودکار و لاگ فعالیت‌ها
- `api/audit.py` — میدل‌ور و ثبت لاگ فعالیت

## امنیت

- تأیید هویت با توکن (`TokenAuthentication`)
- محدودسازی نرخ درخواست (Throttling)
- اعتبارسنجی فرمت و حجم فایل‌های آپلودی
- کنترل دسترسی مبتنی بر نقش در تمامی اکشن‌ها
- لاگ کامل عملیات با IP و کاربر
- متغیرهای محیطی برای تنظیمات حساس
